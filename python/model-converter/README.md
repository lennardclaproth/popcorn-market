# Model converter

This python application is made so that we can convert hugging face models to onnx models (Open Neural Network Exchange).

make sure to install the required packages.

## Resources

1. [onnx](https://onnx.ai/)
2. [huggingface-exporting a model to ONNX](https://huggingface.co/docs/optimum-onnx/onnx/usage_guides/export_a_model#exporting-a-model-to-onnx-using-the-cli)
3. [huggingface-exporting a model to ONNX prorgrammatically](https://huggingface.co/docs/transformers/v4.46.0/serialization)
